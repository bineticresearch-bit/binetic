# .binetic — Model Format Specification

**Version:** 4.0.0  
**Status:** Draft (research phase)  
**Purpose:** Packaging format for the Binetic decision system — weights + heads + ISA + 4D temporal metadata

## Core Design Goals

1. **Packable**: all tensors and head configs in one file
2. **Executable**: the ISA encodes the inference graph
3. **Temporal**: phase-residual metadata for the 4D processor
4. **Ternary-ready**: any quantization (int8, int4, ternary)
5. **Hardware-agnostic**: works on CPU, GPU, or phase-locked accelerator

## File Structure

```
┌─────────────────────┐
│  HEADER (64 bytes)  │  [0:4] Magic "BNET"
│                     │  [4:8] Version (u32 = 4)
│                     │  [8:12] Opset (u32 = max opcode)
│                     │  [12:16] Flags (u32)
│                     │  [16:24] Meta length (u64)
│                     │  [24:32] Tensors length (u64)
│                     │  [32:40] Instructions length (u64)
│                     │  [40:48] Phase config (u64)
│                     │  [48:64] Reserved
├─────────────────────┤
│  METADATA (varlen)  │  Key-value pairs:
│                     │  - model.architecture
│                     │  - model.hidden_dim
│                     │  - model.hidden_dtype
│                     │  - model.heads (JSON list)
│                     │  - model.genome (JSON)
│                     │  - 4d.phase_default
│                     │  - 4d.tick_length
├─────────────────────┤
│  TENSORS (varlen)   │  Per tensor:
│                     │  - name (u8[16])
│                     │  - shape (u64[8])
│                     │  - dtype (u8) [int8=1,int16=2,uint16=3,fp16=4,fp32=5,ternary=6]
│                     │  - byte_len (u32)
│                     │  - data
├─────────────────────┤
│  INSTRUCTIONS (varlen) │  Per instruction:
│                     │  - opcode (u32)
│                     │  - dst_addr (u64)
│                     │  - src_addr (u64)
│                     │  - size (u32)
│                     │  - bit_width (u16)
│                     │  - phase (f64)
│                     │  - tick (u32)
├─────────────────────┤
│  GATE TABLE (varlen) │  Per gate:
│                     │  - trigger (u32)
│                     │  - expr (string)
│                     │  - params (blob)
├─────────────────────┤
│  TRAILER (64 bytes)  │  - hash (u32[16])
│                     │  - verify signature (u64[8])
│                     │  - ...
└─────────────────────┘
```

## Header Layout (64 bytes)

```c
struct BineticHeader {
    char magic[4];      // "BNET"
    uint32_t version;   // 4 (file format version)
    uint32_t opset;     // max opcode = number of instructions
    uint32_t flags;     // bit flags: 1=ternary, 2=cyclic, 4=phase_safe
    uint64_t meta_len;
    uint64_t tensor_len;
    uint64_t instruction_len;
    uint64_t phase_config; // 4D phase metadata encoding
    uint64_t padding[3];  // reserved
};
```

## Opcode Layout (16 ops)

| Code | Name | Description |
|------|------|-------------|
| 0x01 | EXPERIENCE | Classify input state |
| 0x02 | LEARNING | Gate/mode/magnitude |
| 0x03 | MEMORY | Store/forget/modify |
| 0x04 | TOOL | Tool selection + params |
| 0x05 | REASONING | Pattern/depth/confidence |
| 0x06 | GATE | Conditional branch |
| 0x07 | MERGE | Combine heads (EA?) |
| 0x08 | PHASE | Phase advance |
| 0x09 | ECHO | Phase capture |
| 0x0A | RESERVE | Reserved |
| 0x0B | TERMINATE | Halt / output |
| 0x0C | NULL | No-op |
| 0x0D-0x10 | API | Reserved |
| 0x11-0xFF | User | Custom ops |

## Encoding Rules

### Tensors
Each tensor is stored with:
1. `name` — the head/layer name (e.g. `heads.experience.classifier.weight`)
2. `shape` — 8-dimensional max
3. `dtype` — one of: int8, int16, uint16, fp16, fp32, ternary
4. `byte_len` — total bytes of data
5. `data` — raw bytes

### Phase Metadata (4D)
Every tensor can carry a 4D annotation:
```
addr: u64 — memory address / register index
phase+: f64 — forward timeline phase
phase-: f64 — backward timeline phase  
tick: u32 — the temporal iteration
```

The phase difference `ΔΦ = Φ₊ - Φ₋ (mod 2π)` is the **computed state**. This gives:
1. **Determinism** — the state is a phase-locked value
2. **Time as primitive** — iteration order is explicit, not implicit
3. **Temporal interpretation** — the engine knows exactly when each tensor was last accessed

## Example: 5-Head Mini Model

A `.binetic` file for the 5-head prototype would contain:
- 64 tensors per head
- 5 phase configurations
- An ISA: 15 instructions covering all 5 heads + gates
- The genome: GA evolution metadata

## Verification

The trailer contains:
- Blake3 hash of (header + metadata + tensors + instructions)
- The model's digital signature (Ed25519)
